Three steps to your first route

Pick a model, add keys, point your app at one base URL.

1

Pick a model

Choose from the 1,313 free model endpoints in the catalog: chat, embeddings, image and audio.

2

Add your keys

Paste the free-tier API keys for the providers you want. They stay encrypted at rest, and each client uses one unified key.

3

Point your client at one URL

Set base_url to http://localhost:3001/v1 and send any OpenAI-compatible request. The router picks the provider.

Change only the base URL

Everything you already send to OpenAI keeps working.

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3001/v1",
    api_key="sk-your-unified-key",
)

client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Hello"}],
)
