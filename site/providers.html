Home/Providers

One endpoint, every provider.

The router holds the free tiers of 87 providers in one catalog and serves them through the same /v1 surface: chat, embeddings, images and audio.

Same base URL, four endpoint families.

Every one OpenAI-compatible, so existing OpenAI SDK code works unchanged.

Chat

/v1/chat/completions — routed to the best free chat model, with failover.

Embeddings

/v1/embeddings — vectors from the free embedding endpoints.

Images

/v1/images/generations — image generation through the same router.

Audio

/v1/audio — speech endpoints, OpenAI-compatible.
