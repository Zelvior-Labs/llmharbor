One endpoint, every provider

87 free tiers, one base URL, four endpoint families. Every one is OpenAI-compatible, so existing SDK code works unchanged.

Chat

/v1/chat/completions — routed to the best free chat model, with failover.

Embeddings

/v1/embeddings — vectors from the free embedding endpoints.

Images

/v1/images/generations — image generation through the same router.

Audio

/v1/audio — speech endpoints, OpenAI-compatible.

Also included

An MCP server, plus a signed catalog feed that keeps the model list current. LLMHarbor is free and has no paid plan.
