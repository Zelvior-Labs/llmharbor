A note on Windows 7

The router performs well on legacy hardware — every screenshot in the dashboard was taken on a Windows 7 x86 SP1 machine with 2 GB DDR2 RAM and an Intel Atom N280. If you are still on Windows 7 SP1, download the portable zip from the dedicated release: the latest .exe will not run on that OS. Once extracted, start it and point your client at http://localhost:3001/v1.

Found a bug, or have a suggestion?

OSSLLMAPI is built in the open. If anything is broken, or you have an idea that would make the router better, send it to zelvior@proton.me — bug reports, suggestions and feedback all land there.
