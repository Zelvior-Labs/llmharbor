Three steps to your first route.

No backend to host, no client to rewrite. Pick a model, add keys, point your app at one base URL.

1

Pick a model.

Choose from the 1,313 free model endpoints in the catalog — chat, embeddings, image and audio models, kept current by a signed model-catalog feed.

2

Add your keys.

Paste the free-tier API keys for the providers you want. OSSLLMAPI keeps them encrypted at rest and lets each client use only one unified key.

3

Point your client at one URL.

Set base_url to http://localhost:3001/v1 and send any OpenAI-compatible request. The router picks the provider.

The one thing to remember

Everything you already send to OpenAI keeps working — change only the base URL. The router takes the model name, picks the provider and endpoint, and hands back a standard OpenAI response.

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3001/v1",
    api_key="sk-your-unified-key",
)

client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{ "role": "user", "content": "Hello" }],
)
