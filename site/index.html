One endpoint, every provider. 87 free tiers, one base URL.

The router holds the free tiers of 87 providers in one catalog and serves them through the same /v1 surface: chat, embeddings, images and audio.

Same base URL, four endpoint families: /v1/chat/completions, /v1/embeddings, /v1/images/generations and /v1/audio, every one OpenAI-compatible.

Set it up in three steps. No rewrite, no proxy config.

  1. Add a provider key

    Open the dashboard, paste a key from any of the 87 providers, and it is encrypted and stored in the vault.

  2. Call /v1

    Point any OpenAI-compatible client at http://localhost:3001/v1 with the unified key. Existing SDK code runs unchanged.

  3. The router picks

    Every request is routed to the best free model, with failover and per-key budgets tracked in the window you saw above.

Questions, answered. In plain words.

What is OSSLLMAPI?

OSSLLMAPI is a modified version of freellmapi made by Zelvior Labs. It aggregates the free tiers of 87 LLM providers, 1,313 free model endpoints and about 10.1 billion free tokens a month, behind one OpenAI-compatible /v1 API, with encrypted key storage, automatic failover and per-key usage tracking.

Is OSSLLMAPI free?

Yes. OSSLLMAPI is MIT-licensed and free to self-host. The free model catalog ships as a monthly signed snapshot; a premium subscription at ossllmapi.co delivers the live catalog the same day new models, quota changes and compatibility fixes land.

How do I call OSSLLMAPI?

Point any OpenAI-compatible client at http://localhost:3001/v1 with the unified key from the dashboard. Chat, embedding, image and audio requests all use the same base URL, so existing OpenAI SDK code works unchanged.

How does the router pick a model?

For every request the router picks the best available model from your fallback chain, then falls over to the next provider when one is rate-limited or over its free-tier cap, tracking token usage per key so you stay under every provider's limit.

Which platforms does OSSLLMAPI run on?

Desktop apps for Windows, macOS and Linux, an Android APK, an iOS IPA, a Docker image for self-hosting, and a CLI. All of them are downloadable from the GitHub releases page.

Are my provider keys safe?

Keys are stored encrypted at rest. The dashboard exposes a single unified API key, and per-key token budgets keep every provider under its free-tier cap.
