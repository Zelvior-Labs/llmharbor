The router does the work. You keep one key.

Four jobs turn a pile of free-tier keys into one dependable endpoint. Each is a page of its own.

Picks the best model

Every request is routed to the fastest model that can serve it, from your ordered fallback chain.

How it routes

Falls over on rate limits

When a provider throttles or hits its cap, the next one takes the request before your caller sees it.

Failover

Keeps keys encrypted

Provider keys are encrypted at rest. Clients only ever see one unified key, minted in the dashboard.

The key vault

Counts tokens per key

Usage is tracked per key against every provider's free-tier cap, so you never quietly pass a limit.
